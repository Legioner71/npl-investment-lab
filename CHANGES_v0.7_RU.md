# Версия 0.7 — карта риска и доходности

Добавлен раздел «Ризик — дохідність». X — снижение NPV в стрессе / (цена покупки + начальные расходы), Y — базовая IRR. Размер круга — пиковый капитал. Для всех оценок действует общий дисконт. Стресс относительно базы: множитель доли плательщиков ×0,8; будущих расходов ×1,25; задержка +3 месяца. Цены и расходы в момент 0 не меняются. Это не вероятность убытка.

Шесть синтетических примеров плюс текущая оценка. Снимки агрегированных потоков сохраняются в браузере; можно добавлять свои оценки после загрузки CSV, переносить снимки через JSON, выгружать таблицу CSV. Это не полный каталог проектов: исходные реестры и ML-истории в снимках не сохраняются.

Проверено: 9 групп финансовых проверок карты; 28 Python-проверок исходных расчётов (8 тестов тяжёлых моделей пропущены); 13 проверок JS-стратегии, CSV. В браузере проверены выбор точки и таблицы, общая ставка, сохранение после перезагрузки, неизменность снимка при изменении цены, импорт корректного / ошибочного JSON, удаление и восстановление, выгрузки JSON и CSV. Выгруженные строки CSV сверены с формулой. Исходные финансовые движки, модели и данные не изменены.

Запуск: распаковать всё и открыть START_WINDOWS.bat. Существующие настройки Python и инструкции GitHub сохраняются. Подробные правила — RISK_MAP.md.
