# Версия 0.6: премиальный интерфейс

Графитовая тема, изумрудные акценты, SVG-иконки, улучшенные таблицы и отчёты. Главный экран объединяет денежный поток и инвестиционный вывод. Сценарии доступны сверху; параметры открываются кнопкой «Параметри». Расчётные движки, модели, исходные данные и правила стратегии v0.5 не изменены.

Проверено: изменение цены и восстановление параметров, стресс-сценарий, переходы между всеми разделами, прогноз до покупки, сравнение моделей, стратегия, открытие инвестиционного отчёта. Python: 28 расчётных проверок и 3 проверки локального сервера прошли; 8 тестов тяжёлых моделей пропущены в базовом окружении. 13 JS-проверок стратегии и CSV-проверки прошли. Нативный запуск Windows не выполнялся.

Установка прежняя: распаковать архив и запустить START_WINDOWS.bat. GitHub Pages публикует папку dist через включённый workflow.
