# NPL Investment Lab 0.9

Полный комплект для локального запуска и GitHub Pages.

## Быстрый старт

1. Распакуйте весь архив.
2. Установите Python 3.10 или новее.
3. Windows: откройте START_WINDOWS.bat. macOS/Linux: python3 run_local.py.
4. Пройдите шесть шагов в верхней панели программы.

Для интерфейса Node.js, GPU и установка ML-библиотек не требуются. Не открывайте index.html напрямую: нужен локальный сервер.

## Единый проект

Данные → прогноз → план и бюджет → финансовая оценка → риск → решение и факт.

Все расчётные разделы используют текущий реестр и выбранный источник прогноза. ML: 12 месяцев при наличии истории; сценарный прогноз: 36 месяцев. Без истории ML недоступна. Неоценённые договоры не считаются неплательщиками; затраты на них сохраняются. План применяется явно и учитывается один раз. Зафиксированное решение хранит первоначальные потоки независимо от текущих настроек.

Подробная актуальная инструкция: **PIPELINE_RU.md**. Схемы входных данных: PREPURCHASE_SCHEMA.md и STRATEGY_90D.md. Разделы документов с версиями 0.8 и ниже являются историей соответствующих модулей; для их связи в 0.9 используйте PIPELINE_RU.md.

## Сохранение

Нажмите «Зберегти проєкт». JSON содержит реестр, историю, настройки, выбранный план, исходное решение и введённый факт. Для восстановления используйте «Відкрити дані / проєкт». Настройки Монте-Карло сохраняются; сами симуляции запускаются повторно или экспортируются отдельно.

## Python CLI

Для единого проекта нужен также Node.js:

    python python/project.py dist/project-demo.json --output project-result.json

С Монте-Карло:

    python python/project.py dist/project-demo.json --mc-params mc-params.example.json --output project-result.json

python/valuation.py сохраняет отдельный прежний сценарный режим. Он не является заменой CLI единого проекта.

## Ограничения

Пилот использует синтетические данные и демонстрационную ML-модель. Требуются калибровка и проверка на истории компании. Строки платежей, эффект действий, расходы и неопределённость — модельные предположения. Юридические ограничения задаются входными статусами, а не устанавливаются автоматически программой.

Публикация: GITHUB_PAGES_RU.md. Проверка комплекта: python scripts/check_package.py.
