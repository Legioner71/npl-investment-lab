# Версия 0.8 — Монте-Карло

Добавлен раздел «Монте-Карло» для текущего реестра и настроек оценки. Три графика: распределение NPV, месячные диапазоны накопленного баланса, число платных договоров. Отдельные вероятности NPV < 0 и невозврата вложений; P90 капитала, устойчивая окупаемость, квантили, среднее худших 5% NPV.

Сегментные вероятности сохранены; гауссовы общий и заёмщицкий факторы создают зависимости без изменения маргинальных p. Ограниченный разброс условных сумм; связанный шок расходов и задержки. Платежи и расходы не обрезаются; расходы всех договоров сохраняются. Старые финансовые модели и ось X карты не меняются. Это сценарная демонстрация, без калибровки на украинской истории; ML на 12 месяцев не подставляется.

Расчёт в Worker, 500–20000 симуляций при бюджете count × draws <=100 млн, seed, остановка. Изменение исходных данных маркирует результат устаревшим. JSON с параметрами / результатами без реестра, CSV симуляций, HTML-отчёт с тремя графиками. Результаты MC пока не сохраняются автоматически при обновлении страницы и не импортируются обратно в UI.

Для обычного интерфейса Node и ML-библиотеки не требуются. Дополнительный Python CLI использует то же JS-ядро через Node.js. Пример параметров: mc-params.example.json. Подробности: MONTE_CARLO.md.

Проверки: 10 групп MC + Python CLI; прежние 9 групп карты, 13 стратегии, CSV и 28 Python-проверок (8 тяжёлых тестов моделей пропущены). В браузере проверяются расчёт, три графика, маркировка старого результата, смена параметров, отчёт и выгрузки. HTML-диалог с графиками проверен; загрузка HTML в облачном браузере не подтверждена. Печать PDF отдельно не проверялась. Окончательные результаты проверок приведены в TESTING.md. Нативный Windows-запуск в этой среде не проверяется; локальный сервер проверен в Linux.
